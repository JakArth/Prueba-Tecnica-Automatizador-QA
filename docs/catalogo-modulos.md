# Catálogo de módulos y detalle de cada item

## 1. Zapatos

### Objetivo
Validar que el catálogo de zapatos se visualiza correctamente, permite filtrar productos y que el usuario pueda acceder al detalle del producto.

### Validaciones principales
- La sección se carga sin errores.
- Aparecen productos con nombre, precio e imagen.
- El usuario puede abrir el detalle del artículo.
- Se puede agregar al carrito desde la vista de detalle.

## 2. Bolsos

### Objetivo
Comprobar la navegación y gestión del catálogo de bolsos.

### Validaciones principales
- La vista del módulo muestra los productos esperados.
- Los filtros o categorías funcionan correctamente.
- El detalle del bolso presenta información completa.
- El flujo de compra se puede ejecutar desde esta categoría.

## 3. Cinturones

### Objetivo
Asegurar que la categoría de cinturones mantiene una experiencia consistente con el resto del sitio.

### Validaciones principales
- Se cargan productos y precios correctos.
- Las tarjetas del producto contienen la información necesaria.
- La acción de compra se procesa sin errores.

## 4. Accesorios

### Objetivo
Verificar la correcta visualización y compra de artículos complementarios.

### Validaciones principales
- Los accesorios aparecen en la categoría esperada.
- El usuario puede navegar al detalle.
- La información del producto es coherente.
- El carrito refleja la selección correctamente.

## 5. Outlet

### Objetivo
Garantizar que la zona de promociones o liquidaciones presume un comportamiento correcto y visible.

### Validaciones principales
- Los productos con descuento se muestran correctamente.
- Los precios y promociones son visibles.
- El flujo de compra funciona con artículos outlet.

## 6. PQRS

### Objetivo
Validar el proceso de presentación, consulta y resolución de peticiones, quejas, reclamos y sugerencias.

### Validaciones principales
- El formulario de PQRS se visualiza correctamente.
- Se aceptan datos obligatorios y validaciones.
- Se envía correctamente la solicitud. (Esta se omite dado que el ambiente no es de pruebas)
- Se muestran mensajes de confirmación o errores esperados.

## 7. Mi cuenta

### Objetivo
Asegurar que el usuario autenticado puede consultar y administrar su información personal.

### Validaciones principales
- El usuario puede iniciar sesión.
- El perfil se carga con la información correcta.
- Se puede actualizar datos como nombre, correo o teléfono.
- Los cambios se reflejan correctamente en la cuenta.

## 8. Bonos de regalo

### Objetivo
Validar que el flujo de bonos de regalo funciona como mecanismo de compra o regalo de valor.

### Validaciones principales
- La sección se muestra con contenido correcto.
- El usuario puede generar o utilizar un bono.
- El sistema valida condiciones y mensajes de error si aplica.

## 9. Account

### Objetivo
Revisar la gestión general de la cuenta del usuario dentro del portal.

### Validaciones principales
- Registro exitoso con datos válidos.
- Validación de campos obligatorios.
- Actualización de perfil.
- Cierre o sesión y acceso de nuevo.
